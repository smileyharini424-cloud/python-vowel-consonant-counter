# Count Vowels and Consonants

## Explanation

This program counts the number of vowels and consonants present in a given string.

## Problem Statement

Write a Python program to count vowels and consonants in a string entered by the user.

## Features

* Accepts text from the user
* Counts vowels
* Counts consonants
* Ignores spaces and special characters

## How It Works

Each character is converted to lowercase and checked to determine whether it is a vowel or consonant.

## Technologies Used

* Python 3

## Data Structure Used

* String

## Methods Used

* `input()`
* `lower()`
* `isalpha()`

## Program Flow

1. Read a string
2. Convert it to lowercase
3. Check each character
4. Count vowels and consonants
5. Display the results

## Sample Input

```text
Python Programming
```

## Sample Output

```text
Vowels: 4
Consonants: 14
```
